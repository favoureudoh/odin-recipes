## 🍳 Odin Recipes

This project is my implementation of the first project in **TOP** curriculum. It serves as a practical, hands-on foundation for mastering HTML structure, navigating relative file paths, and building multi-page web architecture from scratch.

### 🛠️ Project Overview
The primary goal of this project was to reinforce core HTML concepts by translating problem statements and design requirements into clean, functional code. The result is a simple recipe website featuring a main index page that routes to individual recipe pages containing ingredient lists, step-by-step cooking instructions, and images.

### ✨ Key Learnings & Skills Demonstrated
- 🏗️ **HTML Document Structure:** Boilerplate setup, semantic hierarchy (`<h1>`–`<h3>`, `<p>`), and clean code formatting
- 📝 **Text Formatting & Lists:** Using unordered (`<ul>`) and ordered (`<ol>`) lists to structure ingredients and cooking steps clearly
- 🔗 **Relative Links & File Routing:** Connecting multiple pages across subdirectories using relative file paths (`../`, `./`)
- 🖼️ **Media Integration:** Embedding and sizing images locally and via external URLs with proper accessibility attributes (`alt`)
- 💡 **Problem-Solving & Hands-On Execution:** Deconstructing page layout requirements and translating them directly into raw HTML code without relying on frameworks or templates

### 🛠️ Built With
- **Language:** HTML5
- **Version Control:** Git, GitHub
- **Code Editor**: Visual Studio Code
